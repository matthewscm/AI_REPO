Project Overview

This project focuses on the development of an intelligent bottle-sorting system that integrates computer vision and machine learning techniques to automate the identification and classification of recyclable and non-recyclable bottles. While this classification pipeline could be applied to many different applications, this system is designed to interact with UR3 which will 'sort' the bottles once correct classification has bee made.

We have used YOLOv8 ONNX based object detection model to locate the bottle in real time, while a Support Vector Machine (SVM) classifier uses extracted features (width, height, aspect ratio and dominant HSV values) to determine whether a bottle is recyclable.

While it is noted that the conjunction of two seperate classification techniques is unecessary and YOLO would be more than capable of handeling all classification to a high accuracy, we wanted to challenge ourselves to incoorporate 2 seperate newly learned techniques.

Discussion

Challenges

1. Having correct dependencies and OpenCV 4.9 installed for correct image pre-processing. Setting the tunable parameters (confidence score and NMS) to ensure bottles are correctly identified and not duplicated. Finally, the system was initially developed with a YOLOv8n ONNX model, but lacked the computational accuracy to identify a range of bottles. To overcome this challenge, the ONNX model was upgraded from the nano model to a larger, standard model. This lead to a substantial increase in confidence scores for bottles and accurate bottle detection.

2. There were challenges around the HSV feature extraction when targetting only the dominent label colour. Elements like see-through bottles, noisy backgrounds or multi-colour labels would make it dififcult to return a single colour without skewing the hue. This was done by cropping the range to the typical label region and filtering out near 0 values (black, white, grey). However outside of our controlled envrionment, these solutions narrow the scope of what can be correctly detected.

3. Collecting a substantial amount of data to lead to a high quality result. The data collection required access to a RealSense RGB-D camera so there was limited time to collect data and test it. The data would sometimes pick up other "bottles" in the background infiltrating the training data so it was important to filter that after developing the data sheet.

Limitations

1. The system currently draws detail from two different camera poses to gather sufficient data on the bottle. This sets a certain time and perceptive limitation on the physical control and range of the UR3.

2. It only uses colour and dimensional data of the bottle to classify it, this data can be subject to poor lighting conditions in the workspace, reflective labels / bottles and geometric deformations - additionally in a real worl application these features will generally not determine the 'recyclability' of a bottle.
